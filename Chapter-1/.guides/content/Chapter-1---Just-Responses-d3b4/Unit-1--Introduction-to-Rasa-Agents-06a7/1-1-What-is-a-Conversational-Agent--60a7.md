Rasa builds **conversational agents**: systems that communicate with humans in natural language. The architecture supports many different ways to manage dialogue, from hard-coded to fully autonomous.
 
| Skill type | Also called | Pros | Cons | Best for |
|---|---|---|---|---|
| **Guided** | Flows | Predictable, no hallucinations | Can feel rigid | Regulated or process-heavy tasks |
| **Autonomous** | Sub-agents | Flexible, handles open-ended input | Requires careful design | Exploration, research, negotiation |
| **Hybrid** | Flow + sub-agent | Precision when needed, flexibility when not | More complexity to manage | Most production agents |
 
**What this course covers**
 
- **Dialogue understanding**: how an LLM can read user input and selects the right flow or sub-agent.
- **Guided skills**: flows that are deterministic and auditable.
- **Autonomous skills**: sub-agents that reason and act using tools.
- **Memory**: slots that store and recall data across turns.
- **Orchestration**: combining guided and autonomous skills in one agent.
