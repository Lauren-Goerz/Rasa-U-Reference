**What you covered:**
 
- Responses: predefined messages in the domain with optional LLM rephrasing
- Flows: conversational paths with descriptions the Command Generator uses to decide what to run
- System patterns: built-in lifecycle flows that handle common occurances like session start, completion, and some types of conversation repair.
- Configuration: `config.yml`, `endpoints.yml`, and `credentials.yml` and what each one controls
- Training and testing: `rasa train` compiles your files into a model; Rasa Inspector lets you chat with it and trace which flows fired
**Next:** Chapter 2 introduces custom actions, Python code that runs during a conversation and returns dynamic replies.
